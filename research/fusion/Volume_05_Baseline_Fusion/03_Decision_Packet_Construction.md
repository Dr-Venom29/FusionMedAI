# Decision Packet Construction & Dataset Protocols

## Prediction Pool Extraction & Manifests

To evaluate the baseline ladder without fabricating patient relationships across independent clinical sources, Phase C11.5 establishes a deterministic sampling framework using prediction records extracted directly from official held-out validation sets.

### 1. Prediction Pool Sources

| Modality | Model Architecture & Calibration | Source Dataset | Val Pool Size ($N$) | Pool Construction Rationale & Invariants |
| :--- | :--- | :--- | :--- | :--- |
| **Retina** | EfficientNet-B3 + Temperature Scaling + MC Dropout ($N=25$) | APTOS 2019 Validation Split | $N = 366$ | Full held-out validation cohort ($N=366$). Risk $r_R \in [0, 1]$, Conf $C_R \in [0.5, 1]$, Uncert $U_R \in [0, 1]$, Quality $Q_R \in [0, 1]$, $R_R = 0.929956$. |
| **Foot** | EfficientNet-B3 + Vector Scaling + MC Dropout ($N=10$) | DFUC 2020 Validation Split | $N = 1006$ | Full held-out validation cohort ($N=1006$ patient-clustered). Risk $r_F \in [0, 1]$, Conf $C_F \in [0.5, 1]$, Uncert $U_F \in [0, 1]$, Quality $Q_F \in [0, 1]$, $R_F = 0.922266$. |
| **Clinical** | CatBoost + Isotonic Calibration + Bootstrap ($B=20$) | CDC Indicators Validation Split | $N = 1066$ | Representative validation prediction pool sampled via uniform stride-14 across the full $N=14,911$ validation encounters to maintain comparable order-of-magnitude balance across modality pools. Risk $r_C \in [0, 1]$, Conf $C_C \in [0.5, 1]$, Uncert $U_C \in [0, 1]$, Quality $Q_C \in [0, 1]$, $R_C = 0.825382$. |

The prediction pools are reconstructed from persisted outputs and frozen preprocessing/calibration artifacts generated by the modality-specific pipelines; C11.5 does not generate synthetic probability distributions or mock modality predictions.

Because the source cohorts are unpaired, records from the three pools are combined only as controlled decision packets for behavioral evaluation and are not interpreted as observations from the same patient.

## Controlled Decision Packet Specification

Each packet sampled for evaluation represents a standalone decision instance:

```text
ControlledDecisionPacket:
  packet_id   : "PACKET_000000" ... "PACKET_000499"
  packet_type : "CONTROLLED_DECISION_PACKET" (strictly locked)
  seed        : 115
  retina      : ModalityRecord (sample from Retina pool)
  foot        : ModalityRecord (sample from Foot pool)
  clinical    : ModalityRecord (sample from Clinical pool)
```

### Deterministic Cohort Generation
1. Cohort size: $N = 500$ packets.
2. PRNG: Python `random.Random(115)` and `numpy.random.default_rng(115)`.
3. Replicability: Exact packet sequences are locked and verifiable across platforms via `packet_manifest.json`.
